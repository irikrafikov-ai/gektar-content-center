# ГектарЪ · Контент-центр

Веб-интерфейс генерации и публикации постов (партнёрам / клиентам) + видеопродакшн + календарь выходов.
Контент собирается из материалов проекта на Яндекс.Диске через MCP-коннектор.

## Архитектура
- `public/index.html` — интерфейс (фронтенд).
- `server.js` — бэкенд-прокси: держит ключ Anthropic в секрете и передаёт запросы в Messages API.
  Фронтенд обращается к `/api/generate`, а не к api.anthropic.com напрямую — так ключ не попадает в браузер.

## Переменные окружения (секреты)
- `ANTHROPIC_API_KEY` — ключ Anthropic (обязательно).
- `YANDEX_MCP_URL` — полный адрес твоего сервиса yandex-mcp (с токеном в URL). Именно так контент-центр получает доступ к Яндекс.Диску.
- `HIGGSFIELD_TOKEN` — токен MCP-коннектора Higgsfield для генерации фото/видео (по желанию; без него текстовые посты работают, генерация медиа — нет).
- `PORT` — задаёт платформа автоматически.

## Деплой на Railway
1. Залить этот код в GitHub-репозиторий.
2. Railway → New Project → Deploy from GitHub repo → выбрать репозиторий.
3. Variables → добавить `ANTHROPIC_API_KEY` и `YANDEX_MCP_URL` (и при желании `HIGGSFIELD_TOKEN`).
4. Railway сам поставит зависимости и запустит `npm start`. Публичный URL — в разделе Settings → Domains.
5. Каждый новый коммит в репозиторий → автоматический передеплой.

(Render — аналогично: New → Web Service, Build `npm install`, Start `npm start`, те же переменные.)

## Локальный запуск
```
npm install
ANTHROPIC_API_KEY=xxx npm start
# открыть http://localhost:3000
```

## Каналы публикации (боты) — переменные окружения
Публикация идёт через `/api/publish`, маршрут по аудитории поста (партнёрам/клиентам; видео → как партнёрам).

Telegram:
- `TG_TOKEN_PARTNER`, `TG_CHAT_PARTNER` — бот и канал для партнёров
- `TG_TOKEN_CLIENT`, `TG_CHAT_CLIENT` — бот и канал для клиентов
- `TG_TOKEN` — общий токен-фолбэк, если бот один на оба канала (тогда задай только чаты)

MAX:
- `MAX_TOKEN_PARTNER`, `MAX_CHAT_PARTNER`
- `MAX_TOKEN_CLIENT`, `MAX_CHAT_CLIENT`
- `MAX_TOKEN` — общий фолбэк

Как получить: токен Telegram-бота — у @BotFather; ID канала — добавь бота админом в канал и возьми chat_id (например через @getidsbot или API getUpdates). MAX — токен у @MasterBot в MAX, chat_id из чата/канала.
Заданы только партнёрские переменные — клиентские посты просто не отправятся (статус «ждёт»), и наоборот.
